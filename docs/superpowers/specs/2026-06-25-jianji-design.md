gen'j# 简记（jianji）设计规格

> 个人记账微信小程序 · 设计定稿 · 2026-06-25

## 1. 产品概述

### 1.1 目标

做一个简单易用的个人记账应用，帮助自己养成记账习惯。核心诉求是「快」——比市面复杂记账 App 更轻，只保留记录收支和看统计的能力。

### 1.2 目标用户

- 主要使用者：开发者本人（单用户场景）
- 设备习惯：手机为主，随时随地快速记一笔
- 登录方式：微信授权 + 一键绑定手机号

### 1.3 V1 范围

**做：**

- 快速记账（全屏页 + 数字键盘）
- 按日期查看记录（分组列表）
- 月度统计（环形图 + 分类排行榜）
- 预设 + 自定义分类
- 离线记账 + 云端自动同步
- 5 套内置主题，设置中切换

**不做：**

- 多币种 / 预算 / 资产管理 / VIP
- 数据导出 / 账单分享
- 独立 App 或 H5 版本
- 多账本 / 家庭共享

### 1.4 用户痛点

- 市面记账 App 功能太多，打开后不知从哪开始
- 从打开到完成记账至少 3-4 步，流程长
- 社区、广告、理财课程等干扰信息多
- 独立 App 需下载，小程序用完即走更符合场景

### 1.5 竞品参考

| 产品 | 优点 | 缺点 |
|------|------|------|
| 随手记 | 功能全面 | 入口深，分类过多，复杂 |
| 鲨鱼记账 | 界面清爽，操作简单 | 广告多，统计需付费 |
| 钱迹 | 极简设计，体验好 | 独立 App，需下载 |
| 微信记账本 | 自动同步微信支付 | 不支持手动分类记录 |

## 2. 详细功能列表

### 2.1 记账模块

**F1 — 快速记账（P0 核心功能）**

- 底部居中「+」按钮进入全屏记账页
- 顶部支出/收入切换，默认支出
- 大号金额展示 + 内置数字键盘（非系统键盘，保证输入体验一致）
- 分类宫格：4 列排列，按使用频率排序，末位「+」跳转分类管理
- 备注输入框：选填，支持文字和 emoji
- 日期选择：默认当天，可修改为历史日期（补记场景）
- 「完成」按钮：金额为空时置灰；保存后自动返回明细页

**F2 — 分类管理**

系统预设分类（首次注册自动创建）：
- 支出：🍜 餐饮 · 🚇 交通 · 🛒 购物 · 🏠 居住 · 🎮 娱乐 · 💊 医疗 · 💰 其他
- 收入：💼 工资 · 💸 兼职 · 💰 其他

用户操作：
- 新增自定义分类（名称 + emoji + 支出/收入类型）
- 编辑自定义分类（名称、图标）
- 删除自定义分类（已有记录自动归入"其他"）
- 系统预设不可删除
- 长按拖拽调整排序，记账页宫格同步更新

**F3 — 编辑与删除**

- 明细页点击记录 → 详情页，可编辑金额、分类、备注、日期、类型
- 明细页左滑 → 红色删除按钮 → 弹窗二次确认
- 删除后本地标记 `deleted`，云端软删除

### 2.2 记录查看模块

**F4 — 记录列表（明细页，默认首页）**

- 按日期降序排列，按天分组（今日 / 昨日 / 具体日期）
- 月度汇总卡片（主题色渲染，月支出/月收入/结余）
- 每条记录：分类图标 + 分类名 + 备注 + 金额（支出红/收入绿）
- 点击 → 详情页；左滑 → 删除

**F5 — 月份筛选**

- 明细页顶栏左右滑动切换月份，默认当前月
- 切换后汇总卡片和记录列表同步更新

### 2.3 统计模块

**F6 — 月度统计页**

- 月份选择器，切换历史月份
- 环形图：中心总支出/总收入，外圈分类色块占比
- 分类排行榜：分类名 + 金额 + 百分比 + 横向进度条
- 切换查看支出统计/收入统计

### 2.4 用户与设置模块

**F7 — 我的页面**

入口：明细页顶栏右侧头像 +「我的」文字。

| 菜单项 | 说明 |
|--------|------|
| 外观主题 | 5 套风格切换，即时生效，跨设备同步 |
| 分类管理 | 增删改分类，调整排序 |
| 同步状态 | 待同步条数 + 手动触发同步 |
| 关于 | 版本号、技术信息 |

**F8 — 登录与授权**

- `wx.login` 获取 openid（无感授权）
- 首次打开引导授权页，绑定手机号
- 登录后自动上传本地离线数据
- 后续打开自动登录

### 2.5 数据同步模块

**F9 — 离线记账与同步**

- 操作 → 本地 storage 立即写入（`syncStatus: pending`）→ 加入 `pendingQueue` → UI 即时刷新
- 在线：后台上传云数据库，标记 `synced`
- 离线：保留队列，网络恢复后批量同步
- 冲突处理（V1）：`updatedAt` 最新为准（最后写入获胜）
- 同步失败自动重试；「我的」页显示待同步数

## 4. 技术架构

### 4.1 技术选型

| 层级 | 选择 | 理由 |
|------|------|------|
| 平台 | 微信小程序 | 用户选定；打开快、无需安装 |
| 框架 | Taro 4 + React + TypeScript | 组件化、类型安全 |
| 云端 | 微信云开发 | 免运维，数据库 + 云函数一体化 |
| 本地存储 | wx.storage + 离线队列 | 离线优先，联网后同步 |
| 图表 | echarts-for-weixin | 环形图、排行榜 |
| 主题 | CSS 变量 + Context | 5 套主题即时切换 |

### 4.2 登录

- `wx.login` 获取 openid（无感授权）
- `getPhoneNumber` + 云函数解密绑定手机号
- 首次打开引导授权，之后自动登录

### 4.3 数据流

```
用户操作 → 本地 storage 立即写入（syncStatus: pending）
         → 加入 pendingQueue
         → UI 即时刷新
         → 在线：后台上传云数据库，标记 synced
         → 离线：保留队列，网络恢复后批量同步
```

冲突处理（V1）：以 `updatedAt` 最新为准（最后写入获胜）。

## 7. 主题系统

### 7.1 概述

5 套内置主题，路径：我的 → 外观主题。选择后全局即时生效，本地 storage + 云端 `users.theme` 同步。

默认主题：`warm`（暖阳简约 · 暗夜暖阳）。

### 7.2 暖阳简约（warm）· 暗夜暖阳 ★ 默认

参考鲨鱼记账暖黄基因，但走暗色底 + 差异化视觉，非白底照搬。

**设计理念：** 夜里的暖光 — 暗色护眼，暖黄作光 accent。

**3 色过渡（暖黄系）：**

| 色阶 | 色值 | 名称 |
|------|------|------|
| 1 | #FFD100 | 明黄 |
| 2 | #FFB800 | 暖金 |
| 3 | #FF9500 | 琥珀 |

**暗色基底：**

| Token | 色值 | 用途 |
|-------|------|------|
| --page-bg | #1c1917 | 暖棕黑页面底 |
| --surface | #292524 | 卡片面 |
| --surface-border | #3d3835 | 卡片描边 |
| --text-primary | #fafaf9 | 主文字 |
| --text-secondary | #a8a29e | 次要文字 |
| --expense | #fb923c | 支出 |
| --income | #4ade80 | 收入 |

**5 个差异化特色：**

1. 暗色暖底 — 暖棕黑替代白底，夜里不刺眼
2. 渐变光晕边框 — 结余卡暖黄渐变描边 + 外发光
3. 渐变文字金额 — 结余数字 黄→金→白 渐变
4. 左侧暖黄时间轴 — 日期分组竖向渐变线
5. 发光「+」按钮 — 光晕扩散，暗色中醒目

## 8. 非功能性需求

### 8.1 性能

| 指标 | 目标 | 说明 |
|------|------|------|
| 首屏加载 | < 2s | 小程序冷启动到可交互 |
| 记账提交 | < 500ms | 本地写入 + UI 刷新（不含网络） |
| 记录列表滚动 | ≥ 30fps | 数据量 < 500 条 |
| 环形图渲染 | < 1s | 月度数据量 |
| 小程序包体积 | < 2MB | 含 ECharts 组件 |
| 页面切换 | < 300ms | Tab 切换感知延迟 |

### 8.2 数据安全

- **权限隔离**：云数据库规则 `doc._openid == auth.openid`，用户只能读写自己的数据
- **传输加密**：微信云开发自带 HTTPS 加密传输
- **登录安全**：手机号通过微信官方 API + 云函数解密，不暴露明文
- **敏感数据**：不在本地 Storage 存敏感信息（仅缓存分类、主题等非敏感配置）
- **删除保护**：删除需二次确认；云端软删除，可恢复

### 8.3 可用性

- 支持 iOS 和 Android 端微信（最低版本：微信 8.0+）
- 适配主流屏幕尺寸（iPhone SE 375px 至 Pro Max 430px）
- 网络断开时正常使用（离线优先架构）
- 关键操作（删除记录）需二次确认，防止误操作
- 错误提示友好：网络异常、同步失败等给出明确提示和恢复引导

### 8.4 可靠性

| 场景 | 处理策略 |
|------|----------|
| 离线记账 | 正常保存本地，轻提示「已保存，待同步」 |
| 同步失败 | 保留 pending 队列，自动重试；「我的」页显示待同步数 |
| 未登录 | 引导授权页，登录后上传本地数据 |
| 金额为空 | 「完成」按钮置灰，防止无效提交 |
| 删除记录 | 本地标记 deleted，云端软删除 |
| 网络超时 | 云函数调用超时 10s，超时后走离线模式 |
| 冲突处理 | 以 updatedAt 最新为准，最后写入获胜 |

### 8.5 可维护性

- TypeScript 严格模式，类型全覆盖
- 核心业务逻辑注释完整
- 云函数独立目录，各自独立部署
- 预设分类通过云函数初始化脚本注入，非前端硬编码
- 主题系统使用 CSS 变量，新增主题只需新增变量定义文件

### 8.6 合规

- 不收集用户隐私信息（仅微信 openid 区分用户）
- 数据存储微信云开发国内节点，符合数据本地化要求
- 提供数据清空能力（「我的」页面可清空全部数据）
- 小程序隐私协议声明数据使用范围
