# 简记（jianji）设计规格

> 个人记账微信小程序 · 设计定稿 · 2026-06-25

## 1. 产品概述

### 1.1 目标

做一个简单易用的个人记账应用，帮助自己养成记账习惯。核心诉求是「快」——比市面复杂记账 App 更轻，只保留记录收支和看统计的能力。

### 1.2 目标用户

- 主要使用者：开发者本人（单用户场景）
- 设备习惯：手机为主，随时随地快速记一笔
- 登录方式：微信授权 + 一键绑定手机号

### 1.3 V1 范围

**做：**

- 快速记账（全屏页 + 数字键盘）
- 按日期查看记录（分组列表）
- 月度统计（环形图 + 分类排行榜）
- 预设 + 自定义分类
- 离线记账 + 云端自动同步
- 5 套内置主题，设置中切换

**不做：**

- 多币种 / 预算 / 资产管理 / VIP
- 数据导出 / 账单分享
- 独立 App 或 H5 版本
- 多账本 / 家庭共享

## 2. 技术架构

### 2.1 技术选型

| 层级 | 选择 | 理由 |
|------|------|------|
| 平台 | 微信小程序 | 用户选定；打开快、无需安装 |
| 框架 | Taro 4 + React + TypeScript | 组件化、类型安全 |
| 云端 | 微信云开发 | 免运维，数据库 + 云函数一体化 |
| 本地存储 | wx.storage + 离线队列 | 离线优先，联网后同步 |
| 图表 | echarts-for-weixin | 环形图、排行榜 |
| 主题 | CSS 变量 + Context | 5 套主题即时切换 |

### 2.2 登录

- `wx.login` 获取 openid（无感授权）
- `getPhoneNumber` + 云函数解密绑定手机号
- 首次打开引导授权，之后自动登录

### 2.3 数据流

```
用户操作 → 本地 storage 立即写入（syncStatus: pending）
         → 加入 pendingQueue
         → UI 即时刷新
         → 在线：后台上传云数据库，标记 synced
         → 离线：保留队列，网络恢复后批量同步
```

冲突处理（V1）：以 `updatedAt` 最新为准（最后写入获胜）。

## 3. 页面结构与导航

参考「鱼皮记账」线框，底部 3 Tab + 居中「+」。

### 3.1 底部导航

| 位置 | Tab | 说明 |
|------|-----|------|
| 左 | 明细 | 默认首页 |
| 中 | + | 橙色/暖黄渐变圆形按钮，点击进入全屏记账页 |
| 右 | 统计 | 月度收支统计 |

「我的」不占底栏，入口：明细页右上角 ⚙️。

### 3.2 明细页（首页）

- 月度汇总区（主题各异，默认「暗夜暖阳」见 §5）
- 记录列表按日期分组（今日、昨日、更早日期…）
- 每条：图标 + 备注 + 分类 + 金额
- 左滑删除 / 点击编辑

### 3.3 记账页（点「+」进入，全屏）

1. 顶部 支出 / 收入 切换
2. 中间大字号金额
3. 分类宫格（4 列，常用优先，末位「+」跳转分类管理）
4. 数字键盘（内置，非系统键盘）
5. 底部：日期选择（默认今天，可补记）+ 「完成」按钮

### 3.4 统计页

- 顶部：标题 + 月份选择器（如「6月 ▼」）
- 环形图：中心总支出/收入，外圈分类占比
- 分类排行榜：横向进度条 + 百分比

### 3.5 我的（⚙️ 进入）

| 菜单项 | 说明 |
|--------|------|
| 外观主题 | 5 套风格切换，即时生效 |
| 分类管理 | 增删改分类 |
| 同步状态 | 待同步条数 |
| 关于 | 版本信息 |

### 3.6 子页面

- 记录详情：编辑 / 删除
- 分类管理：预设 + 自定义增删改
- 登录页：首次打开，微信授权 + 绑手机
- 外观主题：5 选 1 列表，带迷你预览和色板

## 4. 数据模型

### 4.1 users

| 字段 | 类型 | 说明 |
|------|------|------|
| _id | string | 云数据库 ID |
| openid | string | 微信 openid |
| phone | string | 绑定手机号 |
| theme | string | 主题 ID（warm/mint/dark/candy/caramel） |
| createdAt | date | 注册时间 |

### 4.2 categories

| 字段 | 类型 | 说明 |
|------|------|------|
| _id | string | 分类 ID |
| userId | string | 所属用户 |
| name | string | 名称 |
| icon | string | emoji 或图标名 |
| type | string | expense / income |
| sort | number | 排序 |
| isDefault | boolean | 是否系统预设 |

**预设分类（首次注册自动创建）：**

- 支出：餐饮 🍜、交通 🚇、购物 🛒、居住 🏠、娱乐 🎮、医疗 💊、其他
- 收入：工资 💰、兼职 💼、其他

### 4.3 records

| 字段 | 类型 | 说明 |
|------|------|------|
| _id | string | 记录 ID |
| userId | string | 所属用户 |
| type | string | expense / income |
| amount | number | 金额（元，2 位小数） |
| categoryId | string | 关联分类 |
| note | string | 备注（可选） |
| date | string | YYYY-MM-DD |
| createdAt | date | 创建时间 |
| updatedAt | date | 最后修改 |
| syncStatus | string | synced / pending / deleted |

### 4.4 本地 storage 结构

```
wx.storage:
├── records[]        # 全量记录缓存
├── categories[]     # 全量分类缓存
├── pendingQueue[]   # 待同步操作队列
├── theme            # 当前主题 ID
└── lastSyncAt       # 上次同步时间戳
```

## 5. 主题系统

### 5.1 概述

5 套内置主题，路径：⚙️ → 我的 → 外观主题。选择后全局即时生效，本地 storage + 云端 `users.theme` 同步。

默认主题：`warm`（暖阳简约 · 暗夜暖阳）。

### 5.2 暖阳简约（warm）· 暗夜暖阳 ★ 默认

参考鲨鱼记账暖黄基因，但走暗色底 + 差异化视觉，非白底照搬。

**设计理念：** 夜里的暖光 — 暗色护眼，暖黄作光 accent。

**3 色过渡（暖黄系）：**

| 色阶 | 色值 | 名称 |
|------|------|------|
| 1 | #FFD100 | 明黄 |
| 2 | #FFB800 | 暖金 |
| 3 | #FF9500 | 琥珀 |

**暗色基底：**

| Token | 色值 | 用途 |
|-------|------|------|
| --page-bg | #1c1917 | 暖棕黑页面底 |
| --surface | #292524 | 卡片面 |
| --surface-border | #3d3835 | 卡片描边 |
| --text-primary | #fafaf9 | 主文字 |
| --text-secondary | #a8a29e | 次要文字 |
| --expense | #fb923c | 支出 |
| --income | #4ade80 | 收入 |

**5 个差异化特色：**

1. 暗色暖底 — 暖棕黑替代白底，夜里不刺眼
2. 渐变光晕边框 — 结余卡暖黄渐变描边 + 外发光
3. 渐变文字金额 — 结余数字 黄→金→白 渐变
4. 左侧暖黄时间轴 — 日期分组竖向渐变线
5. 发光「+」按钮 — 光晕扩散，暗色中醒目

## 6. 错误处理

| 场景 | 处理 |
|------|------|
| 离线记账 | 正常保存本地，轻提示「已保存，待同步」 |
| 同步失败 | 保留 pending 队列，自动重试；设置页显示待同步数 |
| 未登录 | 引导授权页，登录后上传本地数据 |
| 金额为空 | 「完成」按钮置灰 |
| 删除记录 | 本地标记 deleted，云端软删除 |
